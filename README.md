# LAN Sharing App

A cross-platform local area network file sharing application.

## Features
- Transfer files between devices on the same LAN
- Discover available devices on the network
- Real-time transfer progress tracking
- Resume interrupted transfers

## Getting Started

### Prerequisites
- Python 3.8+ (or appropriate runtime for chosen language)
- Local network connection

### Installation
1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run the application: `python main.py`

### Usage
1. Launch the app on all devices
2. Devices will automatically discover each other
3. Select a device to connect and transfer files

## Technology Stack
- Cross-platform networking
- mDNS for device discovery
- TCP/UDP for file transfer
- Modern UI framework
